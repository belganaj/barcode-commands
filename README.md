# تطبيق تأكيد الطلبيات

## التشغيل على GitHub Pages

1. أنشئ Repository جديدًا على GitHub.
2. ارفع الملف `index.html`.
3. من Settings → Pages اختر:
   - Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
4. افتح رابط GitHub Pages من الهاتف.
5. اسمح للموقع باستخدام الكاميرا.
6. اضغط **📷 مسح Barcode** وامسح كود الطلبية.

### ملاحظة مهمة
هذه النسخة تحفظ حالة "تم التوصل" داخل `localStorage` في نفس المتصفح والجهاز. أي أنها مناسبة للتجربة والاستعمال على هاتف واحد، لكن البيانات لا تتزامن بين عدة هواتف.

إذا أردت لاحقًا، يمكن ربطها بـ Google Sheets / Apps Script حتى تكون حالة الاستلام محفوظة مركزيًا ومتاحة من أي هاتف.
